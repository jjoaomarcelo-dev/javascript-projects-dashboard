# JavaScript Projects Dashboard

Dashboard pessoal para registrar e apresentar os exercícios e projetos que desenvolvo em JavaScript.

## Sobre o projeto

Estou desenvolvendo esse dashboard para organizar os exercícios e projetos que faço durante meus estudos de JavaScript. A proposta é manter um histórico da minha evolução prática e, com o tempo, permitir o acesso ao código e à execução de cada trabalho pelo navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro, sem bibliotecas ou frameworks

## Objetivo de aprendizado

Estou construindo o projeto por etapas para consolidar meus conhecimentos em JavaScript, com foco em funções, arrays, objetos, eventos e manipulação do DOM.

Escrevo o código dos exercícios e das funcionalidades que estou estudando sem utilizar IA para gerá-lo. O objetivo é desenvolver autonomia em programação e registrar minha evolução por meio de implementações que consigo compreender e explicar.

Conforme avanço nos estudos, pretendo incorporar TypeScript, React e outras tecnologias ao projeto.

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## Estrutura de arquivos

```text
javascript-projects-dashboard/
├── index.html   # Estrutura da página
├── style.css    # Estilos e responsividade
├── script.js    # Lógica do painel
└── README.md    # Documentação do projeto
```
